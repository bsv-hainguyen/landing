Privacy Policy

Last updated: November 18, 2026

TaskFlow is a desktop app for macOS that keeps task folders next to the code repositories they belong to. This policy explains what data TaskFlow accesses, including Google user data when you connect a Google account, and how that data is used, stored and shared. TaskFlow and this website are run by the TaskFlow team (“we”, “us”).

In short: TaskFlow runs entirely on your Mac and has no server of its own. Data that TaskFlow reads from Google goes straight from Google to your computer. It is never sent to us or to anyone else.

1. Google user data TaskFlow accesses

Connecting a Google account is optional. It is only needed for the Q&A feature, which loads client questions and answers from a Google Sheet. When you connect, TaskFlow asks for these permissions:

  • openid and email: your Google account’s email address, used only to show which account is connected in Settings.
  • https://www.googleapis.com/auth/spreadsheets.readonly: read-only access to Google Sheets that your account can already open. TaskFlow only reads the spreadsheets whose links you add to a task. It never creates, edits or deletes anything in Google Sheets.

TaskFlow does not ask for your name or profile picture, and it does not access Gmail, Google Drive files, Contacts, Calendar or any other Google data.

2. How TaskFlow uses Google user data

  • To show the connected account’s email address in Settings.
  • To load the Q&A tab linked to a task, keep only the rows that belong to that task, and save them as a Markdown file in the task’s qa/ folder on your Mac.
  • To mark which questions are new or changed since the last load.

Google user data is used only for these features. It is not used for advertising, it is never sold, and it is not used to develop, improve or train generalized artificial intelligence or machine learning models.

3. Google API Services User Data Policy

TaskFlow’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. Where data is stored

Everything stays on your Mac:

  • Sign-in token: the refresh token is stored in the macOS Keychain. Short-lived access tokens are kept in memory only and are never written to disk.
  • App settings: the connected email address, the sheet link and the task name on the sheet are saved in ~/Library/Application Support/taskflow/state.json.
  • Q&A files: each load that finds changes creates a new Markdown file in the task’s qa/ folder.
  • Snapshot: the rows from the last load are kept in ~/Library/Application Support/taskflow/qa/ so TaskFlow can tell what changed.

Files saved on your Mac are under your control. If you open them with other tools, such as an AI coding assistant running in TaskFlow’s terminal, that tool’s own terms and privacy policy apply.

5. Sharing

We do not receive, sell, share or transfer Google user data. TaskFlow only connects to Google’s servers (accounts.google.com, oauth2.googleapis.com and sheets.googleapis.com), always over HTTPS. The app has no analytics, tracking or advertising code.

6. Disconnecting and deleting data

  • Disconnect in TaskFlow’s Settings revokes TaskFlow’s access with Google and removes the token from the Keychain. Q&A files you already created stay in your task folders.
  • You can also remove TaskFlow’s access at any time from your Google Account permissions page.
  • Removing a task from TaskFlow deletes its snapshot. To delete all app data, delete the ~/Library/Application Support/taskflow/ folder and any Q&A files you no longer need.

Because we never receive your data, there is nothing stored on our side to delete.

7. Security

Sign-in uses Google’s OAuth 2.0 flow for desktop apps in your default browser, protected with PKCE and a random state value. Tokens are kept in the macOS Keychain or in memory, and all requests to Google use HTTPS.

8. This website

This website is hosted on GitHub Pages. GitHub may log visitor IP addresses for security purposes, as described in the GitHub Privacy Statement. Fonts are served by Google Fonts, which receives your IP address when a page loads. The website does not use cookies, analytics or advertising trackers.

9. Children’s privacy

TaskFlow is a tool for software teams and is not directed to children under 13. We do not knowingly collect personal information from children.

10. Changes to this policy

We may update this policy, for example when TaskFlow adds a feature that uses new data. When we do, we will change the “Last updated” date at the top of this page.
